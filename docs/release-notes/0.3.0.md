**oton 0.3.0** für Macs mit Apple-Chip (macOS 14 oder neuer).

**Neu: oton aktualisiert sich selbst.** Gibt's eine neue Version, kommt eine Mitteilung mit **Update** (oder oben im Menü: „Update to oton …“). Ein Klick, oton lädt, prüft die Signatur, ersetzt sich und startet neu. Nie während einer Aufnahme. Im Terminal: `ot update`.

Von 0.2.x aus: dieses eine Mal noch `oton.dmg` laden und oton im Programme-Ordner ersetzen. Danach kommen Updates von selbst.

Neu installieren: `oton.dmg` laden, oton in den Programme-Ordner ziehen, beim ersten Start [„Dennoch öffnen“](https://github.com/k1tesurfen/oton#der-erste-start). Für die Transkription braucht's [Wolfgang](https://github.com/k1tesurfen/wolfgang/releases/latest).

`oton.app.zip` ist für das Selbst-Update da; zum Installieren die `oton.dmg` nehmen.
